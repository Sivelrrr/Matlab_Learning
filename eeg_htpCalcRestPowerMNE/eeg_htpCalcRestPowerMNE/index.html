    Calculating Resting Spectral Power (Python MNE)

    Overview

    The eeg_htpCalcRestPower function is a powerful tool for analyzing the spectral power of continuous EEG data. It employs Welch’s method, a widely-used signal processing technique, to estimate the power spectral density (PSD) of neural signals. This method involves dividing the signal into overlapping segments, applying a window function to minimize spectral leakage, and averaging the results to produce a smooth and reliable PSD estimate. The function supports analysis of specific frequency bands—such as delta, theta, alpha, beta, and gamma—that are linked to various cognitive and physiological states. It calculates three key power metrics: absolute power (the raw power within a frequency band), relative power (the proportion of power in a band relative to the total power across all bands), and decibel power (a logarithmic representation of power for easier interpretation).

    Customizable parameters allow users to define their own frequency bands, adjust window sizes for frequency resolution, and handle multi-channel EEG data efficiently. The results, saved as CSV files or optionally in Parquet format, are particularly useful in applications such as cognitive state monitoring, clinical diagnostics, and brain-computer interface research, where frequency-specific neural activity provides critical insights. This function combines mathematical rigor with practical versatility, making it an essential tool for EEG spectral analysis.

    Key Features

    • Calculates absolute, dB, and relative power using Welch's method.

    • Customizable parameters for frequency bands, window size, and duration.

    • Saves results as CSV files, with optional Parquet format support.

    Required Inputs

    The function takes the following inputs:

    EEG: An mne.io.Raw object containing EEG data. This data is typically loaded from EEGLAB .set format.

    Optional Parameters (via **args)

    gpuOn: A boolean indicating whether GPU processing is enabled (default is False).

    duration: The duration of data (in seconds) to process (default is 60 seconds).

    offset: The starting offset time (in seconds) for analysis (default is 0 seconds).

    window: The length (in seconds) of the analysis window for Welch's method (default is 2 seconds).

    bandDefs: A dictionary defining frequency bands. By default, standard EEG bands are used (e.g., delta, theta, alpha). outputdir: The directory for saving results. If not specified, results are saved in the EEG file’s directory.

    useParquet: A boolean indicating whether results should be saved in Parquet format (default is False).

    Methods

    Input Validation

    The function validates all optional parameters to ensure correctness. For example:

    • The gpuOn parameter must be either an integer or a boolean.

    • The duration and offset parameters must be numeric.

    • This step ensures the function runs without errors when provided with customized inputs.

    Output Directory Setup

    The function creates a dedicated directory for saving results:

    • If an outputdir is not specified, the function uses the EEG file’s path.

    • The directory is named eeg_htpCalcRestPower and will be created if it doesn’t already exist.

    Signal Processing

    Sampling Parameters:

    • The sampling frequency (fs) is extracted from the EEG data.

    • Window samples (win_samples) are calculated based on the specified window length.

    • Overlap is set to 50% of the window length by default.

    • Validation of Duration and Offset: The function ensures the specified duration and offset do not exceed the available data size. If necessary, it adjusts the duration to fit the available data.

    • PSD Calculation: The power spectral density (PSD) is computed using Welch's method:

    f, Pxx_den = signal.welch(raw_data, fs, window=window, nperseg=win_samples,
    noverlap=noverlap, detrend=False, scaling='density')

    Frequency Interpolation: The PSD values are interpolated to align with a consistent frequency range:

    interp_func = interp1d(f, Pxx_den_scaled[i], kind='linear', fill_value='extrapolate')
Pxx_interp[:, i] = interp_func(freq_range)

    Power Calculation

    The function computes:

    • Absolute Power: Represents the raw power in each frequency band.

    • dB Power: Converts the absolute power to a logarithmic scale.

    • Relative Power: Normalizes the power in each frequency band relative to the total power.

    • Band-averaged power values are also calculated for each frequency band.

    Outputs

    The function organizes the results into three main outputs:

    1. Spectral Power Metrics

    The function outputs three primary spectral power metrics for each frequency band across all EEG channels:

    • Absolute Power: Raw power values in each frequency band.

    • Relative Power: The proportion of power in each band relative to the total power across all bands.

    • Decibel Power: Logarithmic representation of power for interpretability. These metrics are saved as a CSV file named <eeg_filename>_eeg_htpCalcRestPower_band.csv in the analysis output directory. Each row corresponds to a channel, and columns include frequency band metrics and channel identifiers.

    2. Spectrogram Table

    This table contains detailed frequency-by-frequency power values for each channel, organized into absolute power, relative power, and decibel power. The table also includes metadata such as the EEG ID and frequency values. The file is saved as <eeg_filename>_eeg_htpCalcRestPower_spectro.csv.

    3. Quality Index (QI) Table

    The QI table is a summary output that provides a quality index for the analysis. It includes information about the dataset’s validity, potential warnings (e.g., insufficient data duration for the specified analysis), and other diagnostics to ensure reliability. Key fields in the QI table include:

    • EEG ID: The unique identifier for the EEG dataset.

    • Channel Count: The number of channels processed.

    • Duration Used: The duration of data included in the analysis.

    • Window Parameters: The window size and overlap percentage used for Welch’s method.

    • Data Warnings: Warnings such as insufficient data duration or missing channel metadata.

    • The QI table is saved as <eeg_filename>_eeg_htpCalcRestPower_qi.csv in the output directory.

    Additional Notes

    • Ensure the EEG data is preloaded into an mne.io.Raw object.

    • For GPU acceleration, compatible libraries like CuPy should be installed.

    • The frequency bands (bandDefs) can be customized as needed.

    • This function is a robust tool for resting-state EEG power analysis and integrates seamlessly with workflows using MNE and related Python libraries.
