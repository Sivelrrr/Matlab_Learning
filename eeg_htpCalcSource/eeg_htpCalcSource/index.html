    EEG Source Localization

    The function eeg_htpCalcSource is a part of the Brainstorm toolbox, designed for EEG source localization, and employs mathematical modeling to infer cortical activity from scalp-level EEG recordings. At its core, the function uses a forward model, which calculates the expected scalp potentials for a given set of neural sources, and an inverse model to estimate the brain's electrical activity at the source level from observed EEG data. The function uses regularization techniques, such as the Minimum Norm Estimate (MNE), to constrain the solution and improve accuracy.

    The flexibility of this function allows users to tailor their analysis by modifying parameters such as output directories, inverse methods, and processing steps, making it highly adaptable for diverse research needs. By integrating preprocessed EEG data with head models, which incorporate information about the geometry and conductivity of the head, the function refines the spatial mapping of neural activations. This combination of physics-based modeling and computational inversion is critical for translating raw EEG signals into meaningful insights about brain function.

    Function Syntax

    [EEG, status, results] = eeg_htpCalcSource(EEG, varagin);

    Input

    EEG: Main input of the function and a structure with fields such as .data (EEG signal), .srate (sampling rate), .chanlocs (channel info), and .pnts (number of points).

    Optional Parameters

    These parameters provide more control over output paths, inverse models, regularization, and more.

    saveset (Default: false):

    Determines whether the resulting dataset is saved in the specified output directory. Set to true if you want the processed EEG dataset to be saved automatically for later use.

    confirmplot (Default: false):

    Controls whether a confirmation plot of channel locations is displayed and saved. Useful for verifying the channel positions before proceeding with source localization.

    headless (Default: false):

    Indicates whether the function runs in a "headless" mode, assuming Brainstorm is already running in the background. If you're using Brainstorm in a scripting environment and don't need GUI-based interactions, set this to true to avoid interruptions.

    outputdir (Default: tempdir (a temporary directory)):

    Specifies the directory where temporary and output files are saved. Set this to a permanent location if you need to keep intermediate files.

    nettype (Default: EGI128)

    Defines the electrode net type. The default is EGI128. Change this if you're using a different electrode configuration.

    computeheadmodel (Default: false):

    Specifies whether to recalculate the head model. Set to true if the current head model parameters need to be updated or recalculated.

    headmodelfile (Default: false):

    Allows you to specify a template head model file. Use this if you want to load a specific head model instead of recalculating or using a default.

    deletetempfiles (Default: false):

    Deletes temporary files created during processing. Set this to true to clean up after processing, especially for workflows generating large files.

    usepreexisting (Default: false):

    Looks for preexisting files in the output directory and uses them if available, instead of recalculating. Ideal for re-running scripts without duplicating computational efforts.

    resetprotocol (Default: false):

    Deletes and resets the Brainstorm protocol.

    bandef (Defaults: {'delta', 2, 3.5; 'theta', 3.5, 7.5; ...} ):

    Cell array specifying frequency bands

    Methods

    • Dependency Check: Ensures that both EEGLAB and Brainstorm are properly installed and configured before initiating source localization, as these tools are essential for processing and visualization.

    • Protocol Setup: Validates the existence of the Brainstorm protocol required for analysis. If the resetprotocol option is enabled, the function clears and reinitializes the protocol, ensuring a fresh start for subsequent computations.

    • Head Model Management: Handles the acquisition and management of head models used for source localization. If a custom head model file is provided, it is utilized directly; otherwise, the function downloads a suitable model. When the computeheadmodel parameter is set to true, the head model is recomputed to ensure it aligns with the dataset.

    • EEG to Brainstorm Integration: Transforms the EEG dataset in .SET format into a Brainstorm-compatible structure. This process includes mapping channel locations to the head model and loading all necessary configuration files into Brainstorm, ensuring compatibility and accuracy in downstream processing.

    • Source Computation: Performs source localization using the Minimum Norm Estimation (MNE) method. The computed sources are enriched with atlas-based information, allowing detailed anatomical mapping. Additionally, the function extracts scouts' time series data, representing specific brain regions of interest, for further analysis.

    • Output: Incorporates the computed source-localized data back into the EEG structure for compatibility with other EEGLAB-based analyses. If saveset is enabled, the updated dataset is saved, preserving all source-related computations and ensuring the results are ready for immediate or future use.

    Outputs

    EEG : The processed EEG dataset with source-localized data and updated channel locations, which will be stored in the .vhtp.eeg_htpCalcSource.regions. (Note that this EEG should be from a source EEG file not a structure that has already been passed through other functions).

    results : Structure containing processing metadata, including atlases and head models used.

    Use Case

    [EEG2, results] = eeg_htpCalcSource(EEG, 'outputdir', 'path/to/output/', ...
    'nettype', 'EGI128', ...
    'saveset', true, ...
    'confirmplot', true);

    In this example, the function processes an EEG dataset with several specified parameters. The outputdir parameter determines the folder where results, including any generated plots, will be saved. The nettype parameter specifies the electrode configuration used in the recording, such as EGI128 for a 128-channel EGI system, ensuring proper alignment with the head model. The saveset option, when set to true, enables the function to save the updated EEG dataset to a new file for further analysis. Additionally, the confirmplot parametergenerates visual confirmation plots of the source localization results, when set to true, providing an opportunity to inspect the accuracy of the calculations. The function returns EEG2, the processed EEG dataset containing source localization data, and results, a structure with detailed information about the computed sources, enabling streamlined integration of source analysis into EEG workflows.

    Additional Notes

    Required Software:

    • EEGLAB: Ensure it is installed and added to the MATLAB path.

    • Brainstorm: Must be running or configured for headless mode.

    Data Compatibility: Ensure the number of EEG channels matches the specified nettype.
