inflow_ImportMeaXDAT Class

Overview

The inflow_ImportMeaXDAT class is part of the SignalFlowEEG pipeline designed for the Cincinnati Children’s Brain Lab. This class reads and processes .xdat files from MEA systems, importing EEG data, applying signal processing, and configuring EEG channel properties for analysis. If the input file is of a different format, such as .edf, it can also handle this format with adjusted processing.

Class Definition

classdef inflow_ImportMeaXDAT < SignalFlowSuperClass

This class comes from the SignalFlowSuperClass, allowing it to utilize shared methods and properties for signal processing flows in the SignalFlowEEG pipeline.

Constructor

Syntax

obj = inflow_ImportMeaXDAT(varargin)

Details

Purpose: The constructor initializes an inflow_ImportMeaXDAT object, setting up the custom function label and flow mode.

Input arguments: Accepts a variable number of input arguments to pass to the superclass.

Example

importFlow = inflow_ImportMeaXDAT('filepath', 'myfile.xdat');

run Method

Syntax

EEG = run(obj, varargin)

Purpose

The run method processes EEG data from a specified .xdat file, extracting signals and metadata, reformatting channels, and applying channel location mappings. It also supports .edf files if provided. Inputs

obj : An instance of the inflow_ImportMeaXDAT class. varargin: Additional arguments, with args.char_filepath specifying the path of the EEG file.

Outputs

EEG: The processed EEGLAB EEG structure containing the signal data, channel locations, and other metadata.

Processing Steps

Filepath and Network Type: Extracts the file path and sets args.char_netType to MEAXDAT.

File Type Check: The run method checks the file extension. If the file is .xdat, it continues with MEA-specific processing; otherwise, it prepares for .edf files.

XDAT File Processing: XDAT Import Code: Uses allegoXDatFileReaderR2019b to read time range and signal structures for PriSigs, AuxSigs, DinSigs, and DoutSigs. Signal Assignment: The primary signal (signalStruct.PriSigs.signals) is assigned to EEG.data, setting the EEG data structure with 32 channels by default. Channel Configuration: Loads mappings from a .mat file (mea3d.mat) for correct 3D locations. If the file is missing, an error is produced. Channel Renaming: Applies mapping to rename channels according to stage2_map, with the new labels assigned to EEG.chanlocs.

EDF File Processing: If not .xdat, the method treats the file as .edf, adjusting channel selection and loading chanlocs for correct ordering.

Channel Mapping Verification: Verifies and checks the channel locations using eeg_checkset, ensuring that the channels match the expected configuration.

QA and Visualization: Calls util_GetQAData(EEG) for quality assurance on EEG data. Plots EEG data using pop_eegplot.

Example Usage

Importing and Running

% Create an instance with the file path to an XDAT file
importFlow = inflow_ImportMeaXDAT('filepath', 'sample_data.xdat');

% Run the import process
EEG = importFlow.run();

This code will load the .xdat file, extract the relevant EEG data, assign channel locations, and visualize the data with pop_eegplot.

Additional Notes

Channel Mapping Files: Ensure MouseEEGv2H32_Import_Stage1.csv, MouseEEGv2H32_Import_Stage2.csv, and mea3d.mat files are available as they contain essential mapping and location data.

Error Handling: The class includes error handling for missing channel mapping files and unsupported file formats.
