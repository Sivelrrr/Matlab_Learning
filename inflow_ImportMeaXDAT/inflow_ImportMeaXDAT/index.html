    Importing XDAT file into Signal FLow

    Overview

    The inflow_ImportMeaXDAT class is a critical part of the SignalFlowEEG pipeline, designed for the Cincinnati Children’s Brain Lab to process .xdat files from MEA (Multi-Electrode Array) systems. Using proprietary file readers like allegoXDatFileReaderR2019b, it extracts primary and auxiliary signals, decodes metadata, and structures the data into an EEGLAB-compatible format. The class creates a standardized EEG dataset, incorporating fields like signal data, sampling rates, and spatial channel locations to enable advanced analyses.

    In addition to .xdat files, the class supports .edf files with adjusted processing workflows. It remaps channel labels using reference mapping files and integrates precise 3D channel locations to facilitate spatial analysis. Non-relevant channels can be excluded for dataset refinement. Quality assurance features, such as generating QA metrics and visualizing signals with EEGLAB tools, ensure data integrity and usability. Built on the modular SignalFlowSuperClass architecture, the class is both extensible and adaptable, bridging raw electrophysiological recordings with advanced EEG analysis workflows.

    Class Definition

    classdef inflow_ImportMeaXDAT < SignalFlowSuperClass

    This class comes from the SignalFlowSuperClass, allowing it to utilize shared methods and properties for signal processing flows in the SignalFlowEEG pipeline.

    Constructor

    Syntax

    Details

    Purpose: The constructor initializes an inflow_ImportMeaXDAT object, setting up the custom function label and flow mode.

    Optional Inputs For Constructor:

    While the constructor doesn’t explicitly parse varargin, it passes the received arguments to the superclass constructor. Users can include optional parameters that may influence the parent class (SignalFlowSuperClass) or setup behavior. Some potential parameters could be:

    Custom File Labels (flabel)

    Users might redefine the label used for this module to better suit their analysis pipeline.

    Example:

    obj = inflow_ImportMeaXDAT('flabel', 'Custom Label for MEA Import');

    File Input Path

    A specific file path or set of file paths can be passed to override the default obj.fileIoVar.

    Example:

    obj = inflow_ImportMeaXDAT('fileIoVar', '/path/to/your/file.xdat');

    Flow Mode (flowMode)

    If the pipeline requires running this module in a different operational mode, it can be specified here.

    Example:

    obj = inflow_ImportMeaXDAT('flowMode', 'customMode');

    Run Method

    Syntax

    EEG = run(obj, varargin)

    Purpose

    The run method processes EEG data from a specified .xdat file, extracting signals and metadata, reformatting channels, and applying channel location mappings. It also supports .edf files if provided.

    Inputs

    obj : An instance of the inflow_ImportMeaXDAT class. varargin: Additional arguments, with args.char_filepath specifying the path of the EEG file.

    Optional Inputs for Run Method

    The run method also accepts varargin, which could be used to customize various aspects of data processing. While these parameters aren’t explicitly parsed in the provided code, here are potential enhancements that could be passed as varargin:

    File Path Override

    If the user wants to specify a different file path dynamically during execution, it can be passed as an argument.

    Example:

    EEG = obj.run('fileIoVar', '/path/to/alternative/file.xdat');

    Sampling Rate (fs)

    The sampling rate is hardcoded at 1000 Hz, but this could be made configurable for files with different recording frequencies.

    Example:

    EEG = obj.run('fs', 500);

    Channel Exclusion

    Users might want to exclude specific channels beyond the predefined set (e.g., piezo or reference channels).

    Example:

    EEG = obj.run('excludeChannels', [1, 2, 32]);

    Custom QA Flags

    Parameters could be added to control QA behavior or metrics generation, allowing the user to skip QA if desired.

    Example:

    EEG = obj.run('skipQA', true);

    Visualization Toggle

    Signal plotting is enabled by default using pop_eegplot, but users might want to disable it for batch processing.

    Example:

    EEG = obj.run('visualize', false);

    Channel Mapping Files

    The code references mapping files (Stage1.csv, Stage2.csv) for channel remapping. Users could optionally specify alternative mapping files.

    Example:

    EEG = obj.run('stage1Map', '/path/to/custom_Stage1.csv', 'stage2Map', '/path/to/custom_Stage2.csv');

    XDAT File Processing:

    XDAT Import Code: Uses allegoXDatFileReaderR2019b to read time range and signal structures for PriSigs, AuxSigs, DinSigs, and DoutSigs.

    Signal Assignment: The primary signal (signalStruct.PriSigs.signals) is assigned to EEG.data, setting the EEG data structure with 32 channels by default.

    Channel Configuration: Loads mappings from a .mat file (mea3d.mat) for correct 3D locations. If the file is missing, an error is produced.

    Channel Renaming: Applies mapping to rename channels according to stage2_map, with the new labels assigned to EEG.chanlocs.

    EDF File Processing: If not .xdat, the method treats the file as .edf, adjusting channel selection and loading chanlocs for correct ordering.

    Channel Mapping Verification: Verifies and checks the channel locations using eeg_checkset, ensuring that the channels match the expected configuration.

    QA and Visualization: Calls util_GetQAData(EEG) for quality assurance on EEG data and then plots EEG data using pop_eegplot.

    Outputs

    EEG: The processed EEGLAB EEG structure containing the signal data, channel locations, and other metadata.

    Example Usage

    Importing and Running

    % Create an instance with the file path to an XDAT file
importFlow = inflow_ImportMeaXDAT('filepath', 'sample_data.xdat');

% Run the import process
EEG = importFlow.run();

    In this example:

    Instance Creation: The inflow_ImportMeaXDAT object is initialized with the file path to the .xdat file. This step prepares the object with the necessary settings for processing.

    File Import and Signal Processing: The run method reads the XDAT file, extracts primary, auxiliary, digital input/output signals, and time range. It processes these signals into a standardized EEG data structure (EEGLAB format), including channel remapping and metadata assignment such as sampling rate, number of channels, and channel labels.

    Data Validation and Visualization: The processed EEG data undergoes integrity checks (e.g., verifying channel locations and signal format) and is visualized using pop_eegplot, allowing users to inspect the signals interactively.

    Additional Notes

    Channel Mapping Files: Ensure MouseEEGv2H32_Import_Stage1.csv, MouseEEGv2H32_Import_Stage2.csv, and mea3d.mat files are available as they contain essential mapping and location data.

    Error Handling: The class includes error handling for missing channel mapping files and unsupported file formats.
