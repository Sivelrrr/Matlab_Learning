    Overview

    The VHTP toolkit was developed by Cincinnati Children’s Brain Lab to help with the application and reporting of EEG analysis.

    VHTP will allow users to create ready-to-use EEG outputs using simple function that utilizes common EEG toolkits such as EEGLAB and Brainstorm.

    Key Features

    1. EEGLAB Centric Structure

    Every core function in the vhtp toolbox utilizes the EEGLAB SET structure as an input, output, or both.

    2. Extensibility

    With the EEGLAB SET structure as a foundation, the vhtp toolbox is extensible to various EEG systems, enabling integration with custom or external code.

    3. Comprehensive Pipeline

    vhtp offers a full suite of functions covering import, preprocessing, analysis, and visualization stages of EEG data analysis.

    4. High Throughput Capabilities

    Built to handle large datasets, the vhtp toolbox supports parallel processing, batch preprocessing, and binary/CUDA-based ICA for efficient processing of thousands of dense-array EEG files.

    5. Visual Tools for Data Inspection

    Visualization is essential in EEG analysis, and the vhtp toolbox includes tools for topographic, dipole, timeseries views, and artifact rejection.

    6. Export for R Integration

    Default outputs are in CSV format, ready for easy import into R, with data dictionaries included for streamlined R integration.

    7. Quality Control & Audit

    vhtp is designed with audit-ready output, tracking timestamps and processing details for each function. CSV tables provide transparency, summarizing actions such as component removal across EEG datasets.

    8. Clinical Focus

    Tailored for clinical trials, vhtp supports blinded preprocessing and adheres to FDA Part 11 compliance.

    9. BIDS Export Support

    After SET import, data can be organized into directories that conform to EEG-BIDS specifications, facilitating data sharing and collaboration.

    Summary

    Therefore, the VHTP toolkit offers a clean implementation and robust reporting capabilities for EEG analysis. By integrating with major EEG toolkits like EEGLAB, FieldTrip, and Brainstorm, it provides researchers with an efficient and effective means to work with EEG data while maintaining high standards of quality control and visualization.
