    Exporting EEG data into a set file

    Overview

    The outflow_ExportSet class is part of the SignalFlowEEG pipeline developed by Cincinnati Children’s Brain Lab. This class allows users to export processed EEG data into a .set file format compatible with EEGLAB, enabling easy storage and sharing of EEG datasets.

    Class Definition

    classdef outflow_ExportSet < SignalFlowSuperClass

    The outflow_ExportSet class inherits from the SignalFlowSuperClass, which provides a foundation for managing and processing EEG data through a standardized framework.

    Constructor

    Syntax

    obj = outflow_ExportSet(varargin)

    Purpose

    The constructor initializes an outflow_ExportSet object and sets up custom flow function parameters, including labels and mode.

    Inputs

    obj: An instance of the outflow_ExportSet class.

    varargin: Additional optional arguments that configure the file path and step name for exporting.

    Example

    exportFlow = outflow_ExportSet('char_filepath', 'path/to/save/directory');

    Run Method

    Syntax

    sfOutput = run(obj, varargin)

    The run method exports EEG data to a .set file in the specified directory, retaining a consistent naming convention and storing history metadata in the EEG structure.

    Outputs

    sfOutput: The output EEG structure with history and other metadata embedded.

    Key Steps in the run Method

    Initialize EEG: Retrieves the EEG data from the superclass using obj.beginEEG.

    Perform Pre-Export QA: Calls util_GetQAData(EEG) to store pre-export quality assurance data.

    Set Export File Path and Naming:

    Defines the file path for saving the EEG data using `args.char_filepath`, defaulting to the current directory if unspecified.

The filename is derived from the current EEG filename, with an option to append a custom suffix to the filename (`args.char_filename`).

    Store Export History: Logs history information in the EEG.etc.SignalFlow.History field, which tracks changes and metadata over time.

    Export to .set File: Executes pop_saveset to save the EEG data to a .set file, storing it at the specified args.char_filepath with the formatted filename.

    Return the Updated EEG Structure: Outputs the EEG structure, now updated with export history and any additional metadata.

    Example Usage

    % Initialize Export Flow with optional file path
exportFlow = outflow_ExportSet('char_filepath', 'output/directory');

% Execute the export
sfOutput = exportFlow.run();

    This code will save the EEG data to the specified directory as a .set file. If no directory is provided, it defaults to the current working directory.

    Additional Notes

    History Logging: All export actions and parameters are stored in EEG.etc.SignalFlow.History for traceability, which can be useful for data audits or reproducing processing steps.

    File Naming Convention: A customizable args.char_filename suffix can be added to the filename to distinguish this dataset or indicate specific processing steps.
