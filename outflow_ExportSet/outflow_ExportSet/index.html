    Exporting EEG data into a set file

    Overview

    The outflow_ExportSet class is a key component of the SignalFlowEEG pipeline developed by the Cincinnati Children’s Brain Lab. It facilitates exporting processed EEG data into the .set file format used by EEGLAB. EEG data, representing brain activity as voltage fluctuations over time, is typically organized as a matrix of electrode signals sampled at a fixed rate. Alongside this time-series data, the .set format includes essential metadata like event markers, preprocessing history, and quality assurance (QA) metrics, ensuring the dataset is both reproducible and ready for further analysis.

    Scientifically, the class incorporates signal QA metrics both before and after processing to validate data integrity. These metrics might assess signal-to-noise ratios or detect artifacts such as eye blinks and muscle movements. By leveraging EEGLAB’s pop_saveset function, the class ensures the dataset, including all annotations and history, is saved in a format widely recognized in neuroscience. This modular design supports seamless integration within larger workflows, promoting robust and transparent EEG analysis.

    Class Definition

    classdef outflow_ExportSet < SignalFlowSuperClass

    The outflow_ExportSet class inherits from the SignalFlowSuperClass, which provides a foundation for managing and processing EEG data through a standardized framework.

    Constructor

    Syntax

    obj = outflow_ExportSet(varargin)

    The constructor initializes an outflow_ExportSet object and sets up custom flow function parameters, including labels and mode.

    Inputs

    obj: An instance of the outflow_ExportSet class.

    varargin: Additional optional arguments that configure the file path and step name for exporting.

    Optional arguments included in Varagin:

    char_filepath

    Type: Character array

    Description: Specifies the directory where the .set file will be exported.

    Default Value: The current directory (char(pwd)).

    char_stepName

    Type: Character array

    Description: A label or name for the specific step in the SignalFlow pipeline.

    Default Value: An empty string ('').

    Example

    exportFlow = outflow_ExportSet('char_filepath', 'path/to/save/directory');

    Run Method

    Setup the EEG Dataset:

    The researcher initializes a MATLAB environment and ensures the preprocessed EEG structure (EEG) adheres to EEGLAB conventions (e.g., correct dimensions, metadata completeness). This dataset is passed to the SignalFlow pipeline.

    Setting the outflow_ExportSet Class:

    exportObj = outflow_ExportSet('char_filepath', '/path/to/export', 'char_stepName', 'FinalExport');

    • char_filepath: Specifies the directory where the .set file will be saved.

    • char_stepName: Provides a label for the export step for documentation.

    Run the Export Process:

    exportedEEG = exportObj.run();

    • Input Processing: The class collects QA metrics (QADataPre) such as signal-to-noise ratio or artifact density to document the data quality before export.

    • Filename Management: Ensures the filename reflects any user-specified suffix or the default EEG filename structure.

    • Export Command: Uses EEGLAB’s pop_saveset function to write the .set file to the specified directory.

    Validate Output:

    The exported EEG dataset is stored in /path/to/export, ready for reloading in EEGLAB:

    EEG = pop_loadset('filename', 'cleaned_data.set', 'filepath', '/path/to/export');

    The .set file includes the signal matrix, event markers, preprocessing history, and QA metrics (QADataPost), ensuring all analysis details are preserved.

    Outputs

    sfOutput: the processed EEG structure that includes the cleaned time-series data, event markers, and sampling information. It embeds metadata such as preprocessing history, export parameters, and QA metrics in the EEG.etc.SignalFlow.History field, documenting all steps performed during the pipeline. This ensures the dataset is fully traceable and ready for further analysis in EEGLAB or other compatible tools.

    Additional Notes

    History Logging: All export actions and parameters are stored in EEG.etc.SignalFlow.History for traceability, which can be useful for data audits or reproducing processing steps.

    File Naming Convention: A customizable args.char_filename suffix can be added to the filename to distinguish this dataset or indicate specific processing steps.
